# دليل سرج المصوّر — إعادة استخدام الأدلة، 10 نوفمبر 2026

## التسليم

- `frontend/src/UsageGuide.tsx`: دليل داخل التطبيق، 17 خطوة عربية، فهرس وبحث وروابط مباشرة، لوحة مفاتيح، تكبير بالحجم الأصلي، عرض هاتف، وطباعة جميع الخطوات.
- `frontend/src/guideContent.ts`: تعليمات مستقلة عن العرض؛ المسار اليومي ثم الأدوات المتخصصة.
- `frontend/src/usage-guide.css`: هوية سرج الحالية مع أصل Brando Arabic الموجود في المشروع، بلا خطوط نظام بديلة للعربية المصممة.
- `frontend/public/guide/`: نسخ مطابقة لأصول الأدلة السابقة، بلا مصادر المهمة الخاصة أو بيانات المالك. `assets.json` يربط الأصل والحجم وSHA-256 ومراجعة الخصوصية.
- لا chatbot، لا طلب شبكة للذكاء، لا قراءة بيانات مستخدم، لا تشغيل هدف ولا تغيير مصادقة داخل الدليل.

## التكامل

```tsx
import { UsageGuide } from './UsageGuide';
// افتح من زر «دليل الاستخدام» في التطبيق.
{guideOpen && <UsageGuide onClose={() => setGuideOpen(false)} locale={locale} />}
```

يفضّل تهيئة `guideOpen` بوجود `#guide=step-id` عند تحميل الصفحة لتمكين الروابط المباشرة من الخارج. المكون يقرأ رقم الخطوة من hash ويحدثه عند التصفح. تتوفر تعليمات عربية حتى عند اختيار واجهة إنجليزية؛ `locale` يغيّر نص العودة فقط، ولا توجد دعوى اكتمال ترجمة الدليل.

## حدود الأدلة المتعمّدة

طلب المستخدم صراحة عدم إعادة التصوير مطلقًا، وهو أعلى أولوية من خطوات الالتقاط الإلزامية في المهارة. لذلك **لم يتم التقاط أي صورة أو فيديو أو PDF جديد، حتى للتحقق**. لا تزعم هذه النسخة اجتياز بوابة المهارة التي تتطلب لقطة مستقلة لكل إجراء وحالة ومراجعة بكسلات مشروحة نهائية.

- 17 خطوة تعليمية؛ 16 منها لديها صورة مرجعية قديمة. بعض الصور يعاد استخدامها لاستهداف عناصر مختلفة بأسهم ودوائر مرقمة منفصلة عبر SVG فوق الأصل دون تصغيره أو تغيير بكسلاته.
- شاشة اختيار المحلي/المنشور جديدة: شرح نصي صريح، لا صورة مفبركة.
- حقول المطلوب، محرر الاختبار اليدوي، الأرشيف: موثقة من مصدر الواجهة؛ المتوفر صورة مدخل الإجراء فقط. الحالات الفارغة ممثلة بصورتها السابقة.
- صور الأدوات المتخصصة الإنجليزية أقدم من مساحة المختبر الحالية، وموسومة «مرجع محفوظ». وصف الخطوات يعتمد المسميات والحقول الحالية. لا تُعد صورًا للإصدار الجديد ولا قبولًا للمظهر.
- نموذج الملاحظة لقطة مبكرة قبل إخفاء حقل اختيار الملفات خلف زر؛ الفرق موضح. لقطة زر الحفظ معطّل لا تثبت نجاح الحفظ.
- لا توجد صور جديدة لحالات الأخطاء والتحميل، المصادقة الجديدة، OAuth الحي، إعداد Cloudflare، كل اللوحات الطويلة أو الطباعة النهائية. تبقى هذه حدود تغطية مصرحًا بها، وليست حالات جرى تصويرها.
- تاريخ الأدلة 2026-11-10، وأسماء/hash المصادر موثقة. بيانات الالتقاط التفصيلية غير متاحة لكل أصل، فلا يُخترع build/capture timestamp/viewport metadata.

## التحقق المنفّذ

`docs/GUIDE-CHECKS.json`: تشغيل Chromium headless للتفاعل وDOM فقط، بلا استدعاء تصوير. تحميل جميع الصور المعلنة وفكها، البحث، انتقال لوحة المفاتيح RTL، التكبير والإغلاق، عدم تجاوز عرض 1440/390/320 لحالات ممثلة، إثبات glyphs فعلية من Brando عبر CDP، وإظهار 17 خطوة كاملة في print media. لم يُنتج أو يفحص PDF ولم تُراجع بكسلات جديدة. build TypeScript/Vite ينجح. مؤشرات SVG مضبوطة بأبعاد الأصل؛ كل علامة داخل حدوده.

`check_coverage.py` الخاص بالمهارة يشترط صورة raster مشروحة مستقلة لكل خطوة وحالة كاملة؛ لا تمثل مدخلاته نموذج إعادة استخدام الصور مع SVG هذا، ولا ينبغي تزوير manifest لاجتيازه. نستخدم manifest أصول + مصفوفة حدود هنا + فحص DOM مخصص، ونعلن أن بوابة الالتقاط الكامل غير منطبقة على النطاق الذي حدده المستخدم.

## نطاق الخصوصية

رُوجعت الأصول المختارة بصريًا: مشاريع اختبار اصطناعية وأمثلة fixture، بلا بريد حساب مالك، أسرار، رموز وصول، مستند المهمة الخاص أو صوره. لا تشمل الأصول أي قاعدة بيانات أو runtime. حفظت الصورة كما هي والأصل لم يُحذف. نشر المستودع ومراجعته الأمنية الشاملة ضمن مسؤولية مسار النشر، لا ينجزه هذا المكون.
