# تجربة محلية مستقلة / Isolated local demo

شغّل `./scripts/setup.sh` مرة، ثم `./scripts/start.sh` وافتح http://127.0.0.1:5288.

تعرض البداية خيارين: **تجربة لوكال** بلا تسجيل، و**نسختي المنشورة** المحمية بـGoogle. رابط المنشورة اختياري يحدده مالك النشر بمتغير `SARJ_PUBLISHED_ORIGIN`، ولا يمنح أي صلاحية. لا توجد بيانات أو مفاتيح تسجيل دخول المالك في المستودع.

- اللوكال يكتب فقط في `.demo-data/` ويستمع إلى loopback. يمنع origin خارجي، host غير محلي، وطلب تعديل بلا ترويسة التطبيق.
- لا يُقرأ `.data/` أو أي بياناتPostgreSQLأو Googleمن وضع اللوكال. يزيل المشغل متغيرات نشر Googleويفرض مسارالتجربة. يرفض الخادم مساربيانات symlinkوالتعارض مع `.data/`.
- المهمة المرفقة نسخة تدريب منقحة:13حالة، منها11ملاحظة تاريخية بتاريخ10نوفمبر2026. ليست نتائج تنفيذ على جهازالمراجع. حالتان إضافيتان تشغّلان APIمحلية متعمدةالعيب؛ ينبغي اعتمادها وتفعيل إذن التعديل لكلتشغيل. لا تشغّل واجهةالتدريب الحية تلقائيًا.
- لا تُنشأ مشاريعمالكأو تُنقل جلساته. لا يوجد دخولGoogleفي اللوكال. اختيار«ابدأ تجربةالنظام»ليس مصادقة.
- لإفراغالتجربة احفظتقاريرك ثم انقل `.demo-data` إلى نسخةاحتياطية وأعدالتشغيل؛ تعود المهمةالأصلية. لا تحذف `.data`.
- دليل الاستخدام بزر واضح أعلىالواجهة، والعرضالتفاعلي في `/presentation/`. المسافةتكشف العناصر ثم تنتقللشريحة تالية.

## Cloudflare AI

المزود المجاني المرفق يعمل عندطلبك فقط. من«المطلوب»افتح مساعدCloudflareواضغط«حلّل المطلوبمجانًا». تُرسل مصادرالمشروع إلىCloudflare، وتشملصورالمصدرإنوجدت. الناتجمسودةتحتاج مراجعة، ولايقررنجاحالاختبار. توثيقمفصل في [FREE-AI.md](FREE-AI.md).

## نشر مساحتك الخاصة

هذا عملمنفصل: شغّل `SARJ_AUTH_MODE=google` معمالكGoogleواحد ومتغيراتOAuthخادمية، علىHTTPS. لا تعرض وضعdemoعبرTunnelأوproxyعام. لا تضعمفاتيح GoogleأوDBأوCloudflareفيfrontendأوGitHub.
