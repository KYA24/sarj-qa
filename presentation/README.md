# عرض سرج التفاعلي

عرض عربي من 10 شرائح؛ الصور المستخدمة موجودة مسبقًا، ولا يتطلب شبكة لتحميل الخط أو الصور أو مشغّل العرض.

## التشغيل

من جذر المستودع:

```sh
./scripts/start.sh
```

ثم افتح `http://127.0.0.1:5288/presentation/index.html`.

يمكن استخدام أي خادم ملفات ثابتة، أو `npx hyperframes present presentation/composition`. نسخة `index.html` المستقلة هي مدخل التسليم المفضل؛ لا تتطلب تثبيت HyperFrames. الفتح عبر HTTP محلي موصى به لقيود iframe في متصفحات `file://`.

- **Space** يكشف الأجزاء ثم يتقدم إلى الشريحة التالية.
- الأسهم وأزرار المشغل للرجوع والتقدم. **P / Present** لوضع المقدم وفق المشغل.
- اضغط صور الواجهة لفتح الأصل بحجمه الكامل. الصور أمثلة اختبار محلي سابق، وليست نتائج مهمة NZL-217.
- إعداد تقليل الحركة في الجهاز يوقف حركات الكشف، ولا يلغي المعلومات.
- العرض بنسبة 16:9؛ الشاشة الأفقية أنسب للعرض، والشاشة العمودية تحتفظ بكل الإطار داخل المساحة.

## التعديل

- `build.py`: النصوص، الترتيب، ملاحظات المتحدث ومواقع الكشف. بعد تعديله شغّل `python3 presentation/build.py`.
- `composition/assets/deck.css`: الهوية والتوزيع.
- `composition/assets/checks.png` و`results.png`: نسخ من صورتين نظيفتين موجودتين مسبقًا؛ لم يتم تصوير النظام من جديد.
- ملفات الخط مأخوذة من أصول المشروع المعتمدة. مشغلا HyperFrames وGSAP ملفات موزعة محليًا؛ النسخة الحالية 0.9.20 (HyperFrames) و3.15.0 (GSAP).

لا يتضمن هذا المجلد بيانات مالك أو مفاتيح أو قاعدة تشغيل. أصل البرهان على مثال التواريخ: `docs/NZL217-LIVE-TRIAL-20261110.md`، وليس صورة الواجهة المعروضة.

## التحقق

`npm --prefix scripts ci` ثم `npx --prefix scripts playwright install chromium` ثم `node presentation/verify.cjs` (بعد تشغيل التطبيق؛ يمكن تحديد `CHROME_PATH` لمتصفح مثبت و`SARJ_PRESENTATION_URL` لعنوان آخر) يفحص التنقل، التحميل المحلي، الخط الفعلي وأبعاد العناصر **دون التقاط أي صورة**. النتائج في `verification.json`.

تم اجتياز العشر شرائح وكشوفها بـSpace، ثم الرجوع، وتجاهل Space داخل حقل كتابة، وأزرار تنقل رسمية قابلة للوصول، على 1440×900 و390×844 (الأخير مع reduced-motion)، دون أخطاء JS أو طلبات خارجية. CDP أثبت رسم الحروف بخط Brando Arabic المضمّن. قياس DOM لم يجد عناصر محتوى خارج مساحة الشرائح؛ الصور محملة وتفتح كاملة.

`npx hyperframes lint presentation/composition --json`: لا أخطاء؛ تحذيرات متعلقة بانتقالات CSS، مستخدمة عمدًا في عرض تفاعلي لا فيديو حتمي. لا تُشغّل snapshot أو render أو فحصًا يصوّر الشاشة ضمن هذا التسليم: تعليمات خالد تمنع أي إعادة تصوير. التحقق البصري النهائي للشكل الجديد لم يُنفذ بصورة جديدة؛ لا يُدّعى اعتماد جمالي من المستخدم.

### حدود المحتوى الحالية

الشريحة 9 تحدّثت بعد تقرير التنفيذ: المحلي يبدأ بلا تسجيل ببيانات تعليمية منفصلة ومهمة جاهزة. Google خاص بالمالك؛ اختبارات المصادقة تستخدم نقلًا مصطنعًا وليست دخولًا حيًا. عامل Cloudflare منشور، ونجح تحليل النص والصورة عبر واجهة API للتطبيق مع حفظ مسودات مرتبطة بالمصادر. لا ندعي اختبار ضغط أو قبولًا بشريًا لجودة المسودات. إصلاحات المحرك والنتائج لاحقة للمحاولة الأصلية، التي تبقى محفوظة ولا تتحول إلى نجاح آلي بأثر رجعي.
